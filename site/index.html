Setup

This page imports the @utexo/webrgb module from this same deployment and drives whatever window.rgb a wallet injects. Install the KaleidoSwap browser extension, unlock it, then press requestProvider(). Every funds-touching call opens the wallet's confirmation popup; nothing here talks to a server. Use a signet or regtest wallet.

Discovery & conformance

listProviders() asks every installed wallet to announce itself, so a page can offer a picker instead of racing for the single window.rgb slot. runConformance() checks this wallet against SPEC.md using read-only calls only — it raises no confirmation. No wallet installed? Install the in-memory mock and the whole page works without one.
